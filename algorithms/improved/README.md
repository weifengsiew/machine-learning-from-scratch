# Improved Algorithms

These files are copied from `ML_Algorithm_Compare/src/shared/algorithms/` and contain the enhanced versions developed after HW1–HW4.

- `decision_tree.py` adds a configurable `maximum_depth` stopping criterion.
- `random_forest.py` passes `maximum_depth` to every tree in the forest.
- `neural_network.py` adds multiclass support, arbitrary label mapping, automatic weight initialization, multiclass metrics, and original-label prediction.
- `printers.py` supports the neural-network training output.

These improved files are separate from `algorithms/HW1`–`algorithms/HW4`, which remain exact copies of the original coursework source.
